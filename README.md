# 常伴 V2 · 家庭关怀与桌宠陪伴

适老化网页应用：账号与家庭绑定、今日提醒、报平安、生活记录、家属联系，以及内嵌桌宠「团团」。基础功能与桌宠都不调用外部 AI API，不需要模型密钥。

## 双平台部署

同一套业务逻辑支持原 Sites / Cloudflare D1 和新增 Netlify / PostgreSQL 后端。两边账号和家庭数据独立；原 Sites 构建保留为 `npm run build`，Netlify 使用 `npm run build:netlify`。本地仍可 `npm run demo`。详细配置、首次注册绑定、免费额度和上线验收见 [NETLIFY部署.md](NETLIFY部署.md)。

## 免注册体验与桌宠语音

- 登录页可选择免注册体验老人端／家属端，也可使用 `/?demo=elder` 或 `/?demo=caregiver` 直接打开体验。两端在同一次体验中共享虚拟家庭，可切换角色、完成日程、创建安排、查看近七天历史、记录生活和发送站内联系请求。
- 体验数据仅存在当前页面内存中，不读取 Cookie、不访问真实账号／家庭接口、不写入数据库。不同体验页面彼此隔离；刷新或确认重置后恢复样例。它不是两台设备的真实同步演示；跨设备仍需注册并绑定正式账号。
- 体验模式不提供真实拨号或家庭码更换；退出体验不登出已有正式账号。请只输入虚拟资料。
- 桌宠设置新增“桌宠语音陪伴”和语速。默认关闭；开启后需点击“允许播放并试听”或单击团团，才允许本页播报。气泡支持“再听一遍”和“停止播报”，不会累积播放队列。
- 使用设备／浏览器语音合成，不使用麦克风，也不调用模型 API。优先选择设备提供的中文语音；是否联网、音色及中文支持取决于设备。语音不可用时显示文字提示，不影响原有功能。
- 关闭语音或桌宠、打开弹窗、填写表单、切换角色、退出或隐藏页面时停止播报。刷新后即使保留开启偏好，也不会未经再次主动操作突然说话。
- `npm run test:demo` 检查虚拟家庭隔离与历史；`npm run test:demo-voice-ui` 使用模拟语音检查播放授权和停止行为，不播放真实声音。手机实机语音可用性需在目标设备上试听确认。

## 本地打开

需要 Node.js 22.13 或更新版本。在 Windows CMD 中运行：

```bat
cd /d D:\codexwork\changban
npm install
npm run demo
```

已有依赖时可以跳过 `npm install`。PowerShell 中使用 `Set-Location D:\codexwork\changban` 切换目录。

打开 http://127.0.0.1:3000 。关闭服务用 `Ctrl+C`。启动时自动执行尚未应用的数据库迁移，不清空已有数据。本地数据在 `.data/changban.sqlite`，不提交到源码仓库。

服务仅监听本机回环地址，其他手机无法直接打开这个本地链接。本地与线上数据库分别保存，发布代码不会自动搬迁本地测试账号和家庭记录。

## V2 桌宠

登录后默认开启「团团」，在页面内自由走动、停下来张望或打盹。它不会显示在常伴页面以外。

新账号及“恢复默认”的行为配置：自由活动、活泼、主动互动频率“多一些 · 约 2 分钟”、标准大小。已有账号在当前浏览器保存的偏好保持不变，可手动恢复为这组默认设置。

- 单击团团：气泡提醒距离当前时间最近的一件未完成日程（包含稍后提醒），无待办时说明已全部完成。15 秒内再次单击改为轮换闲聊，连续闲聊停止 15 秒后重新提醒。
- 双击／双触团团：老人端展开今日待办，可完成或稍后提醒；家属端展开“家人的日程进度”，查看所有日程及完成记录。单击会等待 400 毫秒区分双击，双击不额外触发单击提醒；键盘 Enter／空格单击互动，方向下键展开面板。
- 拖动团团：改变位置；拖动不会误触日程弹窗。固定模式会保留位置偏好。
- 主动问候：每次进入／刷新常伴，团团出现时立刻问候并提醒查看日程；应用内切换栏目不重复。保留主动问候开关及日常互动频率设置，到点提醒等待入场问候结束后展示。
- 未来日程：主页与两端桌宠面板提供“接下来的安排”，显示具体日期／明天标签和时间；每个重复计划预告下一次日期，过期一次性事项不混入未来安排。未来日程不计入今天的完成比例，不能提前被家属催促或作为今日事项完成。管理列表显示提醒／开始日期，创建一次性日程时实时提示今天或未来的展示位置。
- 事件鼓励：完成事项、报平安或记录生活后给予回应。
- 日程提醒：读取现有日程，不另外创建提醒。稍后提醒以新的时间计算；到期去重，重开页面后汇总今天未提醒过的到期事项。
- 不打扰：避开可操作控件，填写表单或打开弹窗时暂停活动，标签页隐藏时休息；尊重系统减少动态效果偏好。
- 设置入口：顶栏「桌宠」或「我的／设置」→「桌宠与陪伴」。提供总开关、自由／固定、活跃程度、主动互动频率、大小、问候、鼓励、提醒气泡、轻提示音、找回和恢复默认。
- 桌宠偏好按账号保存在当前浏览器，跨设备不同步。健康与家庭记录仍保存在服务端。
- 声音默认关闭；浏览器需要先发生用户交互才能播放音频。关闭桌宠或提醒气泡后，仍保留普通站内日程提示。

角色素材来自 Kenney Animal Pack Remastered（CC0），已本地打包，不依赖素材 CDN。出处见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

### 家属关怀模式与一键提醒

- 家属端单击团团，播报老人今日已完成比例、时间未到与逾期未完成数量，附最近一件日程的状态；15 秒内重复单击仍为闲聊。问候、闲聊和到期提示均采用家属视角。老人新记录完成日程时可收到气泡反馈，首次加载不重播旧完成记录。
- 家属端面板保留已完成日程，显示老人端记录的完成时间；稍后提醒按新时间计算，未到新时间不会误报逾期。面板与主页每 10 秒同步一次。
- 对已到时间且未记录完成的事项，家属可“一键提醒老人”。提醒持久保存在当前家庭，老人打开页面后接收；同一事项全家庭共用 5 分钟冷却，不重复催促，不发送短信／微信或后台推送。
- 老人端保留“家人的小提醒”卡片，即使关闭桌宠也能查看。点“知道了”仅确认收到，家属能看到确认回执；它不等同于完成日程。日程完成、改期、稍后提醒或停用后，过时的提醒不再显示。
- 服务端校验账号角色、家庭归属、今天的日程、完成状态与新提醒时间。家属不能代老人记录完成，也不能访问其他家庭的提醒。完成状态以老人端记录为准，未记录不代表实际未做。
- 数据库迁移 `0002_lively_siren.sql` 仅新增家属提醒表及索引，保留已有账号、家庭和日程。

## 账号与家庭演示

1. 注册老人账号，填写称呼，在「家人」页获取 16 位家庭码。
2. 退出后注册家属账号。首次登录必须填写家庭码、称呼、电话和关系。
3. 家属添加提醒；退出后用老人账号登录，完成事项、报平安、填写记录，并体验团团的回应。
4. 家属查看家庭成员、事项完成情况与联系请求。仅老人能查看／更换家庭码、修改老人资料和记录共享设置。

账号角色由服务端固定，不能在页面切换。一个浏览器的普通标签页共享登录会话；同时测试双端请使用不同浏览器或普通／隐私窗口。退出后顺序切换账号也可以测试。

站点访问权限与应用内账号是两层机制：私有站点默认只有所有者可打开；家庭码不会自动给别人开通站点访问权限。

## 基础功能

- 一次性／每天／每周提醒，添加、编辑、停用和历史完成记录。
- 完成、撤销、10 分钟后提醒；每个日期的状态独立保存。
- 每日报平安、联系请求，以及待查看／已查看／已联系状态。
- 双端家庭成员信息、联系方式和关系展示。
- 每日心情、睡眠、可选血压和备注；老人控制是否向家属共享记录。
- 大字模式、手机布局、键盘可操作表单与弹窗。
- 服务端会话、角色权限、家庭数据隔离和输入校验。
- 每 10 秒与窗口聚焦时刷新家庭记录。

## 当前边界

- 网页打开时提供站内提醒；关闭、锁屏或设备休眠后不保证定时提醒。
- 提醒日期统一采用 Asia/Shanghai（北京时间）。
- 联系请求不会自动拨号、发短信或邮件，需要家属打开页面查看。
- 生活记录用于保存和展示，不提供医疗诊断或调整用药建议。
- 原型账号尚无短信验证、找回密码、账号注销、家庭退出和成员移除功能。

## 技术结构与验证

### 每日日程历史

- 两端底部“历史”及主页“查看每日日程历史”入口，支持选择日期、前后一天、回到今天，以及近 7／30 天汇总。
- 显示当日安排、已完成、未记录完成、完成率、明细和完成时间。今天持续同步；已停用事项单独展示，不进入完成率分母。空日程不计为失败。
- 用追加式日程版本和已有每日操作还原历史，保留当时的名称、时间、频率与备注；之后修改或停用不改写过去。连续几天不打开页面，仍可按既有计划还原这些天的安排，不依赖后台定时任务。
- 从当前家庭首次使用新版本的日期开始追踪完整安排；更早仅显示已有操作并标为旧记录，不臆测未知事项、不计算不完整的完成率。旧操作内容按首次追踪时可用的资料保留。
- 历史只读、按家庭隔离，日期统一为北京时间。“未记录完成”不表示实际未做。数据库迁移 `0003_busy_tarot.sql` 仅新增历史追踪与日程版本表，保留原有数据。
